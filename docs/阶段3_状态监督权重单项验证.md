python scripts/stage2_delivery.py check

  --config configs/agcrn_lite_low_power_state010.json \
  --seed 1 --repeat 1 --tag stage3_state010_s1 \

## 预先规定筛选条件

先要求验证整体 MAE 不高于 C 同 seed；h1和低转非低恢复 MAE 相对恶化均不超过1%；S1 MAE至少改善10%，同时持续低功率 MAE不恶化。上述百分比是筛选门槛，不是已经实现的效果。未通过就保留 C，不继续扩大该候选。

单 seed通过后，补齐0、2种子的匹配验证对照；三对种子全部检查整体和退化约束，并检查逐事件结果，再决定是否进行5种子和独立时间段确认。S1窗口有重叠，不把评分格数当成独立事件数。
