# 文档索引

服务器文档保留安装、当前训练、评估口径和部署说明。通用分析工具在本地保留，已替代的阶段方案归档到项目外。

| 文档 | 用途 |
|---|---|
| [使用指南](使用指南.md) | 安装、数据准备、单模型命令、开发接口 |
| [服务器部署与同步](服务器部署与同步.md) | 首次部署、已有数据更新、同步范围及Git提交 |
| [模型与消融](模型与消融.md) | 既有模型、损失、锚点、低功率头与方法配置 |

| [实验训练](实验训练.md) | 当前固定 M1 早停的 M2 加权九次训练、核验续跑、自动回传包及历史入口 |

所有命令默认在项目根目录执行。实际接口以[ProtocolConfig](../src/wpf_benchmark/evaluation/config.py)与[Evaluator](../src/wpf_benchmark/evaluation/evaluator.py)为准。

脚本入口见[脚本索引](../scripts/README.md)。详细历史阶段材料保留在本地项目外的 experiment-analysis/maintenance_archive/，不作为当前服务器待执行计划。
