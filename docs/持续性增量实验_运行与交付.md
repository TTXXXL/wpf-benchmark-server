# 持续性增量实验：运行与交付

日期：2026-10-09。代码已实现，完整SDWPF训练待服务器执行。首轮验证历史功率、显式历史风况与非线性时间编码的增益，暂不继续C的状态监督权重搜索。

## 1. 固定的首轮矩阵

| 编号 | 模型 | 输入 | seed | 训练次数 |
|---|---|---|---|---:|
| P | 共用锚点持续性 | 最新有限历史功率 | 0 | 0 |
| L0 | increment_linear | 清洗功率历史 | 0、1、2 | 3 |
| L1 | increment_linear | 清洗功率＋风速/风向正余弦 | 0、1、2 | 3 |
| D0 | increment_tcn | 清洗功率历史 | 0、1、2 | 3 |
| D1 | increment_tcn | 清洗功率＋风速/风向正余弦 | 0、1、2 | 3 |

合计 **12次训练、13个结果任务**。两个模型均跨机组共享参数，逐机读取144步十分钟历史，直接输出未来12步。所有输出相对同一个锚点计算，不递归、不累加。残差头零初始化；训练后仍可能劣于持续性。

TCN为hidden32、6块、每块2个kernel3因果卷积，dilation为1/2/4/8/16/32，感受野253，覆盖完整144步。线性模型为四通道历史展平后共享线性头。功率输入模式在网络内屏蔽三个风况通道，同一骨干的两种模式参数总量一致；不把零权重风况参数称为有效信息。

统一采用MAE、逐时距M1有效目标、Adam lr0.001、batch256、stride6、最多30epoch、patience5、weight_decay0、dropout0。无有效目标的批次跳过，日志记录实际使用的样本、批次、目标格与跳过批次。

## 2. 更新已有服务器项目

在原40次实验和阶段3使用的项目根目录执行，激活原来的Python/PyTorch环境：

```bash

python scripts/increment_batch.py plan
python -u scripts/increment_batch.py run
```

`plan`只读取数据、配置与环境，打印13项完整命令，不训练、不写批次状态。`run`逐项核验并训练，最终自动收集交付ZIP。不要同时启动两份`run`。

本轮必须保留原来的 `data/processed/` 和 `reports/`，**不要重新运行 `preprocess` 或 `fit-power-curve`**。默认数据摘要固定为 `033fb4a7a9e0daf8`，缺失或不匹配即停止。这个摘要由处理Parquet和元数据共同生成；不要通过修改 `--expected-data-digest` 绕过首轮匹配要求。仅为本地合成测试/另行明确的新快照才使用覆盖参数。

若服务器项目未连接Git，可以上传新版 `wpf-benchmark-server.zip`，解压到单独的暂存目录，只复制 `src/`、`configs/`、`scripts/`、`docs/`、`README.md` 和 `pyproject.toml` 到现有项目。不要覆盖服务器的处理数据、报告或Python环境。再次运行上述`plan`、`run`。

SSH断开后继续运行的替代命令：

## 3. 中断、失败与复用

```bash
# 中断后继续，或补失败项；完成项经SHA256核验后跳过。
python -u scripts/increment_batch.py run

# 只重新核验、收集，不训练。
python scripts/increment_batch.py collect
```

部分完成显示 `PARTIAL N/13 jobs`，退出码2，并保留部分交付包与失败日志。全部完成显示 `COMPLETE 13/13 jobs`，退出码0。未完成训练从头开始，`.pt`只供最佳状态推理，不支持优化器续训。已完成文件被修改或损坏会停止；重复完整结果不会按成绩挑选。代码、支持脚本、配置、数据或环境与冻结计划不一致时停止。

锁在进程退出时自动释放。若仍提示另一进程运行，先确认原批跑是否还在执行；不要删锁文件后启动第二份训练。

## 5. 信息边界与指标解释

训练Day1–196，早停Day197–221；新增密集导出也只读取截止Day221的记录，并以训练末尾143步作为前缀。代码不会读取测试记录或执行测试推理。数据摘要仍读取整个既有Parquet文件的字节以核验冻结快照，这不参与模型预测或配置选择。

早停指标使用stride6、仅验证段内的完整历史窗口；`validation_metrics`为这一分数。`dense_validation.groups`来自验证段全部3588个起报时刻的导出，两者分别命名、不要混算。

锚点统一为历史144步中最新有限功率，全部缺失则回退物理0kW，最终裁剪至[0,1550]kW。旧持续性在常规评估中取最后一格；本轮密集验证参考显式使用最新有限锚点。末格有效时两者一致。不要将这轮缺失回退规则变化静默套用到旧测试结论。

D0/L0是“现有清洗功率历史输入”，清洗功率含风速依赖筛选及同时刻邻机填补，不能称为严格纯本机信息。D1−D0和L1−L0只回答增加显式风况通道的价值。

预先固定历史组：最近6步风速全部有限且位于[0,1)m/s为历史静风；锚点[0,10)kW为历史低功率；最近6步功率全部有限且总体标准差≤5kW为历史低波动。真值低功率与低功率恢复只作事后诊断。分组输出有效格数、覆盖起报日、模型与持续性MAE、绝对差、skill及偏差；持续性MAE为0时skill留空。事件覆盖、真实变化大小、按日配对及跨种子汇总在收到结果后分析。

## 6. 预先固定筛选标准

开发筛选需要总体三种子平均MAE相对持续性改善至少1%，至少2/3种子获益；h1平均相对恶化不超过1%；历史静风/低功率/低波动平均绝对退化各不超过1kW。稀少组必须同时说明覆盖，不能宣称统计确证。

“缺口修复”要求总体保持正收益，h1及三个历史组平均均不差于持续性，各关键项至少2/3种子不退化；随后补5种子和时间回测确认。达到开发门槛仅表示值得继续研究。D1−D0、L1−L0、D0−L0、D1−L1均按同seed配对报告；没有同验证预测的旧A/C/AGCRN不放入本轮排名。

冻结计划中记录阈值及输入边界，收到结果后保留所有种子、各保护组与恢复表现，不只报最佳模型。当前尚无这组完整训练结果，不能提前宣称改进。
