## 需要改正的规格和计划

1. **B2 的科学问题写错了。** M2 同样截零，能测试掩码/群体敏感性，不能单独回答零值是否由清洗制造。应联合 B1 原始标签审计；若要识别截零与非负输出本身的作用，还需另行设计诊断，不改当前 M1/M2 定义。
2. **D2 缺失值要求自相矛盾。** 一处要求恒填零，一处要求两锚点开关全关时不得填零。实际 Forecaster 已有输入处理，锚点路径还需要保留原始缺失状态选择最近有限功率。必须同时检查 Forecaster 和 Network，不能仅拆构造参数。
3. **旧布尔预设和新参数需要可区分“未传”与 false。** 否则默认 `current_power_skip=False` 会与新的显式开关冲突。见下方接口设计。
4. **D 的输出开关仍捆绑反馈。** 若同时改变输出和递归反馈，应称“残差输出及反馈路径”，不能据此单独证明输出参数化的贡献。
5. **版本取证先于决定重跑。** A/B/C 五种子指纹一致且均能溯源，应保留。一个配置/seed 的预测完全复现不证明其他配置等价；新的关键因子对照仍应统一版本。
6. **计划不能以“M2 现象消失”直接取消机制研究。** M2 改变目标群体，误差变化须拆成交集与新增群体，并结合历史主群体和恢复代价决定。
7. **D3 不应列为本轮 A/B/C 的必验项。** 模型未改时无需声称完成拆分前后逐位兼容；D 一旦启动，先建立原实现基线再修改。
8. **种子同向与测试段不确定性分开。** 预测单元包含时距重复与时间、空间相关。跨种子 SD 描述训练随机性；配对时间块重采样应在同一块保留全部机组与时距，预先定块长并报告敏感性。

## D 的修正版设计，尚未实现

建议接口为 `current_power_skip: Optional[bool]=None`，三个新开关也允许 None。无旧预设时，未指定的新开关默认 false；显式旧预设 true/false 将三者展开为全 true/全 false；同时显式指定新开关时，仅允许与该预设一致，否则报错。解析出的三个有效开关写入模型配置和结果元数据，不只保存用户输入。

- `anchor_output` 控制残差输出及其递归反馈。
- `anchor_input` 控制首步使用池化前最近有限功率，或池化后最后一格功率。
- `readout_zero_init` 控制读出层初始化。绝对功率路径的零初始化是归一化坐标的零，未必对应物理 0 kW；这点须按 scaler 定义核验。

只在 `anchor_output or anchor_input` 时选择 anchor；先从未池化、保留缺失状态的历史选择最近有限功率，再按生产 Forecaster 的既有策略统一输入清理。不要增加一个未经识别的 `fill_nonfinite` 实验因素。低功率头要求 `anchor_output=true`；其输入、融合和反馈仍需按实际实现核验。

兼容要求应分开：既有生产 Forecaster 的 true/false 预设在有限、末端缺失、连续缺失、全缺失历史上逐位回归；直接调用 Network 的非有限输入行为另立契约。若统一清理会改变旧 Network(false) 的 NaN 传播，不得同时声称这一路逐位相同，需明确保留兼容路径或记录契约变更。保存原实现权重和输出、固定 CPU 种子与线程，不能修改后才生成“原基线”。

阶段一保留 2×2：固定 `anchor_input=false`，改变 `anchor_output` 与 `readout_zero_init`；阶段二单独改变 `anchor_input`。先在验证集筛查候选，再冻结关键对照与评价终点，补五种子和独立时段。固定输入后收益消失只是信息旁路候选解释；存在交互或随机性时允许报告“无法分离”。比较 AGCRN 与 Lite 敏感性须统一损失和开关含义。
