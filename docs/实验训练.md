# 实验训练与结果交付

所有命令在服务器项目根目录、原来的 Python/PyTorch 环境执行。更新代码保留原处理数据、报告和权重。

## 当前实验：M1/M2 训练口径比较

```bash
git pull --ff-only
python -u scripts/run_study.py --study m2_robustness
```

共六次训练：现有 C 模型分别使用 M1、M2 训练和早停，各跑 seed 0、1、2。架构、MAE、状态损失权重 0.05 及其他参数一致。训练 Day1–196，验证 Day197–221；只运行验证，不读取测试段。

本轮检验扩大目标监督并改变早停口径的整体效果；M2 提升不能单独证明输入噪声鲁棒性。密集 M1/M2、M2 额外评分样本、静风、恢复和 h1 指标由本地统一复评分后决定下一轮，不用两组各自的早停分数直接比较优劣。

训练前核验冻结数据摘要 `033fb4a7a9e0daf8`、处理文件 SHA256 和模型源码摘要。预检失败时把报错交回，保留原快照，不重新运行 preprocess 或 fit-power-curve 来通过检查。旧命令已经跑出结果但没有新入口清单时会停止，交回已有结果，避免重复训练。

全部完成后自动生成：

```text
reports/studies/m2_core_20261010_v1/m2_core_20261010_v1_delivery.zip
```

把这个 ZIP 交回即可，包含六份验证 JSON、六份最佳权重、训练日志、配置、冻结清单及文件哈希。用户无需自行分析。CSV 中的是训练早停口径，密集双口径分析在本地完成。

SSH 中断后原样执行同一条训练命令。入口核验身份、配置、数据、源码、运行环境和每个结果文件的 SHA256，只跳过完整的已完成项；失败的一次从头训练，不恢复 epoch。重复、损坏或跨版本结果会停止，不挑最新或较好的结果。批跑共用项目锁。

只重建回传包、不启动训练：

```bash
python scripts/run_study.py --study m2_robustness --collect-only
```

只查看六条训练命令、不写文件或训练：

```bash
python scripts/run_study.py --study m2_robustness --dry-run
```

## 后续实验与历史入口

新的验证实验优先复用 `scripts/run_study.py`，在 `configs/studies/` 放一份计划，引用已有模型配置。明确模型、种子、变体和冻结指纹后，通过同一个入口训练和交付。每轮交付前整理已替代的配置与说明；一次性分析及历史证据留在项目外。

以下旧训练入口保留，因为已有消融和批跑仍依赖它们。只在明确要求复现时使用；更新代码无需重跑历史实验。

| 入口 | 用途 |
|---|---|
| `scripts/rerun_low_power_review.py` | 八组五种子的低功率历史实验，默认复用处理数据 |
| `scripts/rerun_graph_ablation.py` | 图骨干、损失与当前功率开关消融 |
| `scripts/rerun_m1.py` | 旧 M1 基线套件，也是批跑公共执行模块 |

这些入口有各自的准备与续跑规则，先使用 `--help` 和 `--dry-run`。旧 M1 套件会进行数据准备，不应在当前冻结数据上启动。历史详细操作说明及阶段 2/3 工具已归档到本地项目外的 `experiment-analysis/maintenance_archive/`，不随服务器仓库分发。

模型细节见[模型与消融](模型与消融.md)，结果口径见[评估与结果分析](评估与结果分析.md)，部署与整理规则见[服务器部署与同步](服务器部署与同步.md)。
