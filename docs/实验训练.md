## 后台运行、续跑与交付

需要 SSH 断开后继续训练时，先完成上述预检，再执行：

```bash
mkdir -p reports/studies/lite_pitch_20261010_v1
nohup python -u scripts/run_study.py --study lite_pitch > reports/studies/lite_pitch_20261010_v1/batch_console.log 2>&1 < /dev/null &
```

查看进度：

```bash
tail -n 40 reports/studies/lite_pitch_20261010_v1/batch_console.log
```

每个完成项记录结果、最佳权重和训练日志的 SHA-256。中断后原样执行 `python -u scripts/run_study.py --study lite_pitch`，入口只跳过身份与文件哈希完整的完成项；失败的一次从头训练，不恢复 epoch。重复、损坏或跨版本结果会停止，批跑共用项目训练锁。

全部六项完成后自动生成并打印：

```text
reports/studies/lite_pitch_20261010_v1/lite_pitch_20261010_v1_delivery.zip
```

## 结果分析边界

主终点是统一密集验证网格下，最新有限历史功率锚点<10 kW群体的 M1 MAE；按相同种子比较 C_pitch7 与新 C_inputs4。原生早停分数用于选最佳 epoch，不是低锚点主终点；服务器回传包不自动选择“最佳组”。

必须同时报告持续低功率（未来<10 kW）与恢复（未来≥10 kW），以及 M1总体、h1、M2和S1事后群体；检查去重目标、低锚点事件等权、历史桨距>89°/≤89°、原始历史完整/含缺失及叶片大差值子群。既有冻结验证切片含桨距，本地可加载回传权重统一推理，分析脚本和结果只留在本地。

官方目标掩码会大量排除高桨距下仍低功率的目标；S1的一些历史桨距变化来自填补。固定评测口径收益不能直接解释为全部停机/恢复机制，也不能证明识别了限电或故障。S1由未来风速/真值定义，仅用于诊断。三种子是小规模配对试验，不能据此声称正式交互效应或独立大样本显著性。

本轮不因实现新增数值验收阈值，不以测试结果选组，也不自动追加种子。先分析六次完整结果，再决定是否保留新增输入。
