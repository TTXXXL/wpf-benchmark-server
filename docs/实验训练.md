### 冻结口径与判定

D1s 的固定27维是20维历史基础、3维桨距状态和五成员预测的均值/总体标准差/最小/最大；D0 为同20维基础加同4维预测统计。双方只在原 E1 共同历史有限性支持集 A_policy 上拟合/动作，新增潜在27维/24维覆盖只作诊断，不放宽支持。拟合 M1有效低锚点的恢复概率（真值≥10 kW）；外层真值、未来风速、未来桨距均不得成为预测输入。

固定 R1、强度1、q=25%。校准分母 N 包括全部 M1有效低锚点评分格，即使历史不可用；`k=max(1, round(0.25*N))` 只在可用有限概率中排序，按可用数截断，`tau=nextafter(p[k-1], +inf)`，用 `p<tau` 纳入边界全部并列。它不是可用概率的第25百分位，外层不重排、不重设 tau，也不保证25%实际动作率。

校准恢复 MAE 恶化超过0.5%则整折冻结 R0，不能算主动通过。拟合单类、输入异常、必要分母不可定义、优化失败等保留为 technical_invalid；校准有效但外层零动作标 valid_no_outer_action。各折回退明细互斥记账。

主口径先平均五成员绝对误差，再计算相对收益，不是先平均预测后算 MAE。共享特征与门控意味着4/5同向不是五次独立门控复现。固定等权均值预测另作影子输出，拥有自己的收益、去重/事件、校准及外层保护；部署资格同时要求主口径和影子自己的检查通过。

主工程门槛全部预设：三折有效校准且外层实际动作；pooled M1低锚点收益≥2%；至少2/3折正收益；至少4/5成员跨折正收益；每折及 pooled 的 M1/M2 恢复与低锚点 h1 恶化≤1%、总体恶化≤0.5%；pooled M1唯一目标及折内低锚点事件段等权收益均为正。D1s对固定q25% D0的共同支持集增量≥2个百分点且≥4成员改善，是独立的增量证据，不代替相对 C 的基本门槛。

报告 MAE、ME、过预测比例，区分评分格、唯一目标、事件段单位；事件键为折/机组/因果低锚点段起点，跨折不合并，不宣称独立物理事件。pooled按误差和有效分母合并，macro-fold为三个相对收益的算术平均，仅作敏感性。固定策略的折内目标日 bootstrap（2000次，seed20261012）只描述目标日组成不确定性，不覆盖训练与选型，也不新增置信区间晋级线。

本地先只读取拟合/校准材料冻结全部模型和数值阈值，再一次性评价外层并独立复核。未过工程线不晋级，但解释须区分技术不可判定、校准拒绝、收益幅度不足、保护失败、单位敏感性及条件性 D0 增量；不能一概写成方法无效。该回测也不能直接证明解决了低风速问题或识别了限电/故障。

## 结果分析边界

主终点是统一密集验证网格下，最新有限历史功率锚点<10 kW群体的 M1 MAE；按相同种子比较 C_pitch7 与新 C_inputs4。原生早停分数用于选最佳 epoch，不是低锚点主终点；服务器回传包不自动选择“最佳组”。

必须同时报告持续低功率（未来<10 kW）与恢复（未来≥10 kW），以及 M1总体、h1、M2和S1事后群体；检查去重目标、低锚点事件等权、历史桨距>89°/≤89°、原始历史完整/含缺失及叶片大差值子群。既有冻结验证切片含桨距，本地可加载回传权重统一推理，分析脚本和结果只留在本地。

官方目标掩码会大量排除高桨距下仍低功率的目标；S1的一些历史桨距变化来自填补。固定评测口径收益不能直接解释为全部停机/恢复机制，也不能证明识别了限电或故障。S1由未来风速/真值定义，仅用于诊断。三种子是小规模配对试验，不能据此声称正式交互效应或独立大样本显著性。

本轮不因实现新增数值验收阈值，不以测试结果选组，也不自动追加种子。先分析六次完整结果，再决定是否保留新增输入。
