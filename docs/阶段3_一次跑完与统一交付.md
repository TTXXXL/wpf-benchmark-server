# 阶段3：一次收齐权重对照与5种子

本轮代替此前“先跑0.10 seed1，再逐项补跑”的安排。所有训练一次排队完成，候选仍只用验证集选方案。当前只改变 `state_loss_weight`，不同时改输入、模型结构、损失类型、掩码或早停规则。

## 为什么同时试0.02和0.10

已交付 C seed0、1 都精确复现各自原始预测，但内部表现不同。测试 M1 持续静风532格，seed0 的平均低功率概率为0.741、MAE为8.035 kW；seed1为0.398、46.168 kW。seed0的概率较高、正常分支幅度较小，两者都参与差异。

另一方面，在同一权重下离线比较 h1 正常分支与最终混合输出，seed0混合后 MAE恶化约0.738 kW，seed1改善约2.402 kW。因此不能把“提高低功率概率”当成唯一目标，也不能把增强状态监督当成已经有效。本轮向下试0.02、向上试0.10，0.05为匹配对照。这些权重是待验证候选值；BCE同时约束低功率与非低功率标签，调大系数并不保证概率统一上升。

## 一次运行

在原来跑40次实验和阶段2的服务器项目根目录，激活原来的Python/PyTorch环境。更新代码，保留现有 `data/processed/` 和 `reports/`，**不要重新运行 preprocess 或 fit-power-curve**。

```bash
git pull --ff-only
python -u scripts/stage3_batch.py run
```

`run`会自行核验数据、列出进度、依次执行15个任务、复用完成结果，并生成一个交付ZIP。如果需要断开SSH后继续运行，可用以下方式替代上面的第二条命令：

```bash
mkdir -p reports/stage3_batch
nohup python -u scripts/stage3_batch.py run > reports/stage3_batch/batch_console.log 2>&1 < /dev/null &
```

查看进度：

```bash
tail -f reports/stage3_batch/batch_console.log
```

可选的只读预览命令会逐项显示 `reuse` 或 `train`，不会训练或写批次状态：

```bash
python scripts/stage3_batch.py plan
```

单项训练失败后，其余任务继续执行。最终显示 `COMPLETE 15/15` 才代表全部完成；部分成功时显示 `PARTIAL`，退出码为2，已成功的材料和失败日志仍统一打包。重新执行同一条 `run` 命令，只补未完成项；中断发生在某项训练中间时，该项从头训练，其他已完成项跳过。数据、代码、配置在批次中发生变化会停止，不能把混合版本结果当成同一批。操作系统锁防止同时启动两份，进程退出或崩溃后自动释放。

仅重新收集、不训练：

```bash
python scripts/stage3_batch.py collect
```

## 收到后怎么分析和选方案

先按相同checkpoint的归一化参数，在相同环境对3组、每组5种子做Day197–221密集验证推理。所有组对齐相同时间、机组、真实功率和M1掩码，同时保存 `q`、低功率分支和正常分支。

对照整体MAE、h1、持续低功率、低转非低恢复、当前功率10–50/50–200 kW、持续静风S1、逐事件和唯一目标等权结果。早停JSON是575个stride6窗口的分数，不能直接替代3588个密集验证窗口的这些指标。尾部事件留一分析只用于检查结论是否被少数事件支配，不删除它们再报正式成绩；重叠预测格也不当成独立样本。

为这次批跑预先固定筛选条件（不是已实现的改善）：

1. 验证整体MAE的5种子均值不高于C，至少4/5个匹配种子不恶化。
2. h1和低转非低恢复MAE：5种子平均相对恶化各不超过1%，任一种子各不超过3%。
3. S1 MAE的5种子均值至少改善10%，至少4/5种子改善；持续低功率MAE均值不恶化。
4. 检查逐事件、唯一目标等权和留一事件结果；若改善只靠少数尾部事件，或其他事件明显退化，不能仅凭总均值晋级。

只有一个候选通过则选它；两个通过则选验证整体MAE较低的候选，整体均值相同则选S1 MAE较低者；两个均未通过则保留C。所有决定在读取候选测试输出前写明，不用测试成绩反选权重。

选定后，对选中的候选和C在Day222–245做5种子匹配推理和事件/日块分析，权重已齐，不再训练。该时段此前已用于机制诊断，因此属于现有测试时段复核。新的独立时间段验证仍需额外数据或事先冻结、重新处理的独立时间回测方案；本批不能凭重复使用同一数据宣称完成这一项。

如果两个权重方向都没有保住整体、h1和恢复阶段收益，再根据这批内部输出确定一项结构修改。目前提前叠加结构、特征或阈值实验，会使本轮无法判断究竟哪项改变有效。
